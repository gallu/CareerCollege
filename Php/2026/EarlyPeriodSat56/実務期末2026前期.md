# 2025年度 後期 実務 期末試験

試験の回答は、以下の通りにすること。

- dev2.m-f.netサーバのアカウント名 + プログラムが入っているディレクトリ名を記載すること
- コードは「サーバ側に置き」「提出はしない」こと
    + 実際に動作確認をするため

試験の注意事項は以下の通り

- 試験なので「周囲との相談」「他人の答案の覗き見」は不許可
- ネット等を使って調べるのは許可
- コードやSQLを実行 / 確認するのは推奨
- いずれの問題も「書いてある点数」を満点とし、問題があったら適宜減点する
- 本筆記試験での最大点数は60点とする(下記「口頭試験」参照)

提出は、以下の通り

- 「自分の名前+各席番号」.txt のファイル名で提出
    + 1ファイルの中に、すべての回答を記載してください

授業中に自身のDBアカウントの作成をしていない人は、試験中に速やかに以下の方法で申し出てください。  

- Teamsのチャットで「自身のアカウント名」と「DBアカウントが必要である」旨を連絡する

### 口頭試験 について

最終日に口頭試験を行います。  

- 試験は3問
- いずれも、自身が書いたコードから講師が1行選択して質問をするので、その行が「何をやっているか」を回答する
- 正解した場合、1問あたり「筆記試験で得られた点数の 1/3(端数切り上げ)」が加点される

## (問1) 簡単なform入力: 30点

新しくLaravelをインストールするか、あるいは、既存にある `laravel_test` への追記で作成しなさい。

提出物には、「アカウント名」「プログラムを書いたディレクトリ名」を記述しなさい。

簡単なform入力の画面を一式作成しなさい。

項目およびvalidate内容は以下の通りです。

- ニックネーム（`nickname`）
  - 必須、文字列、100文字以内
- メールアドレス（`email`）
  - 必須、メールアドレス形式、255文字以内
- 年齢（`age`）
  - 任意、整数、0以上
- 自己紹介（`profile`）
  - validateなし

画面は以下の2画面を用意しなさい。
URLは、書いてある通りにしなさい。

- **入力画面** `/exam/profile/input`
  - 上述の項目が入力できること
  - validateエラーの時に、エラー内容が出力されること

- **入力完了画面** `/exam/profile/fin`
  - 入力された内容のうち、ニックネーム・メールアドレス・年齢・自己紹介が出力されること

採点項目は以下の通り（各6点）

1. 入力ページが表示されること
2. validateエラーの時にエラー表示がされること
3. validateエラーの時に、入力された値が保持されていること
4. CSRFチェックが適切にされていること（hiddenパラメータを触って確認します）
5. 入力完了画面で、ニックネーム・メールアドレス・年齢・自己紹介が出力されること（XSSがないこと）

## (問2) 簡単なform入力とDBへのinsert: 30点

新しくLaravelをインストールするか、あるいは、既存にある `laravel_test` への追記で作成しなさい。

提出物には、「アカウント名」「プログラムを書いたディレクトリ名」を記述しなさい。

DBを扱うため、マイグレーションとEloquentモデルの作成は必須とする。

### 入力項目とvalidate仕様

- タイトル（`title`）
  - 必須、文字列、255文字以内
- カテゴリ（`category`）
  - 必須、文字列、100文字以内
- 優先度（`priority`）
  - 必須、整数、1～5
- 詳細（`description`）
  - 任意、validateなし

### DB仕様

テーブル名は `exam_tasks` とし、少なくとも以下のカラムを持たせること。

- `title`
- `category`
- `priority`
- `description`

Laravel標準の `id`、`created_at`、`updated_at` を追加してもよい。

### 画面（URLは厳守）

- **入力画面** `/exam/task/input`
  - 上述の項目が入力できること
  - validateエラー時にエラー内容が表示されること
  - validateエラー時に入力値が保持されること

- **入力完了画面** `/exam/task/fin`
  - 入力された **タイトル・カテゴリ・優先度・詳細** を出力すること（XSS対策された表示）
  - **DBにレコードがinsertされていること**

### 採点（合計30点）

- 入力ページが表示される … 6点
- validateエラー時にエラー表示が出る … 6点
- 入力完了画面で、タイトル・カテゴリ・優先度・詳細が適切に出力される（XSSがない）… 6点
- `exam_tasks` テーブルに **正しくinsertされる**（マイグレーション＆モデルを用いた実装）… 12点
